What happens automatically

  • Only a paid, completed cashier order enters the queue.
  • Its status changes to PROCESSING while delivery is active.
  • Every status change creates a delivery audit event.
  • When delivered, the order lifecycle returns to COMPLETED.
  • Cancelled deliveries can be re-dispatched later.
